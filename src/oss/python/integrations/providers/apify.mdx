>[Apify](https://apify.com) is a cloud platform for web scraping and data extraction,
>which provides an [ecosystem](https://apify.com/store) of more than a thousand
>ready-made apps called *Actors* for various scraping, crawling, and extraction use cases.

The `langchain-apify` package wraps Apify Actors as LangChain tools, a retriever, and document loaders. Run prebuilt Actors for search, scraping, and social media, or any Actor from the [Apify Store](https://apify.com/store) by ID.

## Installation and setup

<CodeGroup>
```bash pip
pip install -qU langchain-apify
```

```bash uv
uv add langchain-apify
```
</CodeGroup>

Get your [Apify API token](https://console.apify.com/account/integrations) and either set it as the `APIFY_API_TOKEN` environment variable or pass it as `apify_api_token` to any component constructor:

```python
import os

os.environ["APIFY_API_TOKEN"] = "your-apify-api-token"
```

## Components

### Tools

The package exports tools for common scraping use cases plus generic wrappers for running any Actor by ID. Tools are grouped into three exported lists (`APIFY_SEARCH_TOOLS`, `APIFY_SOCIAL_TOOLS`, `APIFY_CORE_TOOLS`) so you can bind a focused subset to an agent, or compose your own list from individual tool classes.

#### Generic Actor and task tools — `APIFY_CORE_TOOLS`

Run any Actor or task by ID and read items from datasets.

| Component | Description | Docs |
|---|---|---|
| `ApifyRunActorTool` | Run an Actor and return run metadata | [Actor tool page](/oss/integrations/tools/apify_actors) |

#### Generic Actor wrapper

`ApifyActorsTool` is a single-class wrapper for running an arbitrary Actor whose input is passed as a JSON-encoded string. Use this when no dedicated tool above covers your Actor.

| Component | Backing Actor | Docs |
|---|---|---|
| `ApifyActorsTool` | Any Actor (specified at construction) | [Actor tool page](/oss/integrations/tools/apify_actors) |

```python
from langchain_apify import ApifyGoogleSearchTool

tool = ApifyGoogleSearchTool()
```

### Retriever

Use `ApifySearchRetriever` to search the web and return results as LangChain `Document` objects, suitable for RAG chains.

| Component | Backing Actor | Docs |
|---|---|---|
| `ApifySearchRetriever` | [`apify/rag-web-browser`](https://apify.com/apify/rag-web-browser) | [Retriever page](/oss/integrations/retrievers/apify_search) |

```python
from langchain_apify import ApifySearchRetriever

retriever = ApifySearchRetriever()
```

### Document loaders

`ApifyCrawlLoader` crawls a URL on demand. `ApifyDatasetLoader` reads items from a previously completed Actor run by dataset ID.

| Component | Source | Docs |
|---|---|---|
| `ApifyCrawlLoader` | Crawls a URL on demand | [Loader page](/oss/integrations/document_loaders/apify_crawl) |
| `ApifyDatasetLoader` | Reads an existing Apify dataset by ID | [Loader page](/oss/integrations/document_loaders/apify_dataset) |

```python
from langchain_apify import ApifyCrawlLoader, ApifyDatasetLoader
```

### Wrapper

`ApifyWrapper` exposes the lower-level Apify client used by the components above.

```python
from langchain_apify import ApifyWrapper
```

## MCP server

Apify hosts an [MCP server](https://mcp.apify.com) that exposes Actor discovery and execution to any MCP-compatible agent. Use it instead of the LangChain tools above when:

- You don't know at build time which Actors you need and want the agent to discover them at runtime.
- You want access to the full [Apify Store](https://apify.com/store) (25,000+ Actors) without importing individual tool classes.

You can customize the server to include only specific Actors, reducing token usage and keeping agents focused. Configure your selection at [mcp.apify.com](https://mcp.apify.com).

See the [Apify MCP documentation](https://docs.apify.com/platform/integrations/mcp) for setup and authorization, and the [LangChain MCP documentation](/oss/langchain/mcp) for connecting MCP servers to LangChain agents.
